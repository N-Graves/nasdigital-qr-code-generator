QR code generator

Type a link, get a code, download it as an SVG a printer will be happy with. Nothing is sent anywhere — which matters more here than it sounds, because plenty of free QR sites are server-side and can see, log and in some cases track every code you make.

Why in your browser rather than on a server

A QR code is a link, and a link says something about you — where your shop is, what your WiFi password is, which document you are handing round. Plenty of free generators build the code server-side, which means the URL passes through somebody else's machine, and a documented few of them quietly redirect through a tracking domain so they can count the scans. This one never sends the text anywhere, because it never needs to.

Two things that stop a code scanning

The obvious one is contrast. The less obvious one, and the reason a code can look perfect and still fail, is inversion: light modules on a dark background. Many scanners only ever look for dark-on-light and never try it the other way round, so a white-on-black code fails on a good share of phones despite having the strongest contrast there is. Both are checked, and the warning says which one it is.

The third is the quiet zone — the empty margin. It is four modules wide, it is part of the specification rather than styling, and it is not adjustable here, because a code with the margin trimmed off looks tidier and does not work.

The error-correction level you pick is a minimum

Higher error correction lets a code survive dirt, creases and a logo placed over it, at the cost of a denser pattern. The library will quietly raise the level when there is spare room without making the code any bigger — so the figure under the preview is the level actually used, which is sometimes higher than the one you chose. Reporting what you asked for would just be wrong.

SVG for anything printed

The SVG is real vector geometry — one path, integer coordinates, no embedded image — so it scales to a shop window or a business card with no loss. The PNG is drawn module by module at whichever size you pick, rather than by scaling a picture, so its edges stay sharp.
